# Aditya's Data & ML Journey

## Day 1: Data Analytics

### Definition
Data analytics transforms raw data into
useful insights for better decisions.

### Real-world use case
An online store analyzes sales to identify
its best-selling products.

### Four types of analytics
- Descriptive: What happened?
- Diagnostic: Why did it happen?
- Predictive: What might happen?
- Prescriptive: What should we do?
